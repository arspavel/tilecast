# Studio brand font licenses

Tilecast Studio bundles three variable upright fonts for its interface:

- Exo 2 (headings)
- Manrope (text)
- JetBrains Mono (technical values)

The font files are sourced from the Google Fonts repository and remain licensed
under the SIL Open Font License 1.1. The corresponding license text for each
family is included in this directory.
